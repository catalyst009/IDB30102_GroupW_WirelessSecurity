### 2. Frameworks, Libraries, and Technical Documentation
* **TensorFlow Lite for Microcontrollers (TinyML):** Used for deploying the lightweight Random Forest/CNN classifier to the ESP32 hardware. 
  * Documentation: https://www.tensorflow.org/lite/microcontrollers
* **Scikit-Learn:** Utilized in the preliminary Python scripts for training and evaluating the Random Forest model.
  * Documentation: https://scikit-learn.org/
* **Pandas & NumPy:** Used for data preprocessing, cleaning, and multi-sensor feature fusion operations.
  * Documentation: https://pandas.pydata.org/
* **TShark:** Network protocol analyzer intended for baseline packet capture verification on the test-bed.
  * Documentation: https://www.wireshark.org/docs/man-pages/tshark.html
